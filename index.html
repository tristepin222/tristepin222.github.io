C++ Vulkan Game Engine

In Progress

A modular, data-oriented game engine prototype built entirely from scratch in C++20 using the Vulkan graphics API. Designed around a custom Entity Component System with a clean two-project workspace: a reusable static library engine and a sandbox game that consumes it, similar to how Unity separates runtime from editor scripting.

C++20 Vulkan GLSL / SPIR-V ECS Dear ImGui ImGuizmo GLFW GLM CMake
  • Custom ECS Registry (dense component storage)
  • Vulkan render loop & push constants instancing
  • WYSIWYG ImGui editor with entity hierarchy
  • 3D gizmos (translate / rotate / scale)
  • Raycast viewport picking (bounding-sphere)
  • Infinite procedural world grid shader
  • Generic component serialization registry
  • Automated shader compilation (glslc)

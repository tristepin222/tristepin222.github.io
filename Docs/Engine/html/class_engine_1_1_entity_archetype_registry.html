Detailed Description

Singleton that holds all registered entity archetypes in insertion order.

Populate via REGISTER_ENTITY_ARCHETYPE (or REGISTER_ENTITY_ARCHETYPE_SEP for entries that need a separator before them). The hierarchy panel reads this registry at runtime to build its "Create" / "Create Child" menus automatically.

Detailed Description

System that drives SpriteRenderer components.

For every entity with a SpriteRenderer the system:

  1. Creates (once) a shared unit quad Mesh — 1m × 1m, facing +Z.
  2. Adds a Mesh component pointing to that quad.
  3. Creates a dedicated Material using the "sprite" shader (transparent alpha-blend).
  4. Each frame, syncs colour, texture, and sortOrder to the material / transform.

Flip is passed through the push constants (scale/fade are repurposed as flipX/flipY) so no mesh rebuild is required when the user toggles flipX or flipY.

The existing RenderSystem draws the Mesh+Material pair automatically — no changes to the render pipeline are required.

Detailed Description

A disk asset (.tileset JSON) that owns an ordered list of TileAssets. At runtime, a CPU-side atlas is built by packing every tile texture into a single RGBA image, which is uploaded to Vulkan once. This gives the TilemapSystem a single draw call per tilemap.

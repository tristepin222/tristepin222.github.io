Unity-style 1-line macro for auto-registering custom components into the engine.

The second argument is a menu path of the form "Category/Display Name". Both category and display name are used to build the hierarchical "Add Component" popup automatically — no manual editor code is required.

Examples: REGISTER_COMPONENT(HealthComponent, "Gameplay/Health"); REGISTER_COMPONENT(AudioSourceComponent, "Audio/Audio Source"); REGISTER_COMPONENT(SomeComp, "Rendering & Lights"); // plain category, display name auto-derived

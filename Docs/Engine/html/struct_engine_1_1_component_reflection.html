Detailed Description

Reflection metadata and ECS callbacks for a component.

The menuPath field drives the "Add Component" popup hierarchy. It is in the form "Category/Display Name" — for example: "Rendering & Lights/Sprite Renderer" If displayName is empty the editor derives one from name at render time.

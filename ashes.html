Crown of Ashes

// system simulation
Real-time procedural planetary terrain and atmosphere rendering in Unreal Engine 5
// motivation

Why I built this

I started Crown of Ashes to explore the math and architecture behind large-scale procedural games. Building a system that seamlessly transitions from star system orbital simulations down to individual planetary landing terrains presents a massive set of challenges in coordinate precision, multi-threaded calculations, and procedural asset instantiation.

By decoupling physical universe generation laws from runtime Unreal components, the project simulates physical constants, orbital tracking, and biological genotypes deterministically based on seed values.

// modular architecture

Module breakdown

The codebase is split into dedicated modules to separate high-level gameplay systems from lower-level astronomical math and rendering adapters:

  • AG
    ImperiumAstroGenesis (Astrophysics Core)
    A pure C++ math module that seeds multiverse physical constants (gravity multiplier, molecular cohesion, strong force peak), star classifications (mass, temperature, spectra), binary stellar configurations, Keplerian planetary orbits, and biological genotype profiles for dynamic ecology.
  • ER
    ImperiumEcologyRuntime (Visual Adaptor)
    Generates procedurally deformed terrain meshes, climate maps, and orbital visual rings. It maps physical laws directly to Unreal assets, scaling skeletal bones, dynamically adjusting clear coats/moss in Material Instance Dynamics, and tuning Control Rig foot stance width based on a planet's gravity.
  • CO
    CrownOfAshes Game Module
    Houses high-level gameplay systems (quests, dialogue, reputation). It features custom PCG (Procedural Content Generation) graph integration and Spawners that coordinate with the runtime ecology to instantiate specific base blueprint variants for simulated creatures.
// technical achievements

Key engineering accomplishments

Keplerian Orbital Visualizer

Computes planetary orbital coordinates in real-time using Kepler's laws of planetary motion. The system draws orbital vectors based on inclination, eccentricity, and semi-major axes, maintaining exact deterministic paths for satellites and binary planets.

Sliding Grid Treadmill

To solve floating-point precision issues when exploring infinite planetary surfaces, the world director manages a 3x3 sliding grid of procedural terrain chunks centered around the player. Chunks are dynamically repositioned and refreshed as the player crosses coordinate thresholds.

Gravity-Driven Control Rig & Morphs

Rather than using static meshes, spawned creatures dynamically adapt to local planetary constants. The Ecology Assembler scales skeletal bones (representing physical load under high gravity) and tunes animation parameters like leg placement interpolation speeds and stance widths in the Control Rig.
